# Catalog triage — content-mapping.csv ownership map (TC-M6-04 decomposition)

Generated 2026-10-18 by TC-M6-04 (t_12f350af) triage. Source of truth for row
ownership: this file maps every one of the 1048 rows in docs/content-mapping.csv
to exactly one owning Kanban card. No row is deferred, duplicated, or dropped.
If a card's scope changes, update this map in the same commit.

## Triage decisions (binding for all catalog cards)

1. **One owner per row.** A row's `implementation_status` may only be flipped to
   `done` by the owning card, and only when the id-stability harness
   (RegistrationGameTest + ContentMappingIdContractTest) resolves it.
2. **Block row vs tile-entity row.** A `block` row = registration of the block
   with ALL its original metadata variants, placement, drops, and static
   behavior. The `tile_entity` row for a machine = the tile entity behavior.
   The block-class owner implements the meta→tile factory; feature cards
   implement the tile classes. Meta map below is binding.
3. **Shared registration files.** Each catalog card registers its content in its
   OWN DeferredRegister holder classes under `registration/catalog/` (e.g.
   `CatalogResourceBlocks`) and adds exactly one wiring line in
   `ModRegistration.init`. Do not edit sibling cards' holder files.
   `docs/content-mapping.csv` is edited only for rows you own (targeted patch).
4. **Recipe ownership.** Recipe-type systems own their recipe data rows:
   arcane_shaped/shapeless → TC-M4-03, crucible → TC-M4-05, infusion →
   TC-M4-04, infusion_enchantment → TC-M6-05, multiblock_structure → the
   structure's owner. Plain vanilla recipes (crafting_*, smelting,
   smelting_bonus) ride with the output's owner; furnace-behavior rows
   (smelting/smelting_bonus) belong to the furnace owner (TC-M6-04c).
5. **OreDict rows** ride with the owner of the stack they register.
6. **Id contract unchanged:** new_id = `thaumcraft:` + lower(original path)
   (D-001 addendum). Catalog cards must not rename ids.
7. **Runic gear split:** runic amulet/ring/girdle → TC-M6-07 (named in its
   title); pure baubles (goggles, vis amulet, thaumostatic harness/girdle,
   bauble blanks) → TC-M8-02. Both consume the TC-M8-01 accessory layer.
8. **Warded block / portable hole** are owned by TC-M6-03 (created by the
   warding / portable-hole focus spells).
